# Vehicle Sales Dashboard

This project is a web application developed for the TripleTen Sprint 5 project.

The application analyzes vehicle sales advertisement data and provides interactive visualizations.

## Features

•⁠  ⁠Vehicle odometer histogram
•⁠  ⁠Price vs. odometer scatter plot
•⁠  ⁠Interactive charts created with Plotly
•⁠  ⁠Web application created with Streamlit
